# Role Summary

Write the summary field for the job analysis.

## Requirements

- Maximum 20 words
- Describe the role, its seniority, and its primary technology
- Be concrete and specific to the job description
- Use professional recruiter language

## Structure

1. Role title or function (e.g., "Senior Java Backend Engineer")
2. Seniority level (only if stated or clearly implied)
3. Primary technology or stack (only if stated)

## Examples

- "Senior Java Backend Engineer working with Spring Boot and PostgreSQL"
- "Mid-level Frontend Developer focused on React and TypeScript"
- "Lead Data Engineer with AWS and Spark experience"
